# Chapter 5: Propulsion and Propulsion Installation Criteria

## Core Idea
Section 7 covers propulsion system and installation airworthiness criteria — engine/propulsion unit behavior plus air-vehicle installation interfaces. Installation is in-scope, not only the bare engine credential.

## Frameworks Introduced
- **Propulsion unit criteria**: Qualitative airworthiness expectations for the propulsion system itself.
- **Installation criteria**: Air-vehicle integration factors that can void an otherwise acceptable propulsion unit.

## Key Concepts
- Propulsion airworthiness includes the unit and its air-vehicle installation.
- Inlets, mounts, controls, and related interfaces can void unit-only credentials.
- Propulsion software and control loads need configuration control.
- Supplier and integrator evidence both belong in closure packages.
- Maintenance actions can invalidate installation assumptions if uncontrolled.

## Mental Models
- A credentialed engine in a bad installation is still an airworthiness problem.
- Propulsion criteria couple tightly to structures, flight, and fire/safety domains.
- Configuration control of propulsion software/control loads matters as much as hardware.

## Anti-patterns
- **Engine-only thinking**: Ignoring inlet/exhaust/mount/controls integration.
- **Untracked propulsion software**: Thrust/control maps changing outside the basis.
- **Maintenance escapes**: Field adjustments that invalidate installation assumptions.

## Key Takeaways
1. Treat propulsion and installation as one airworthiness object.
2. Map criteria to both supplier and integrator evidence.
3. Coordinate with flight performance/flying qualities (ch04).
4. Control propulsion-related software under ch07 practices.
5. Capture maintenance/inspection needs that preserve propulsion airworthiness.
