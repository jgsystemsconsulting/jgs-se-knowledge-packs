# Patterns — MIL-HDBK-516C

## 1. Certification Basis Workshop
- **When:** Program start or major configuration change.
- **How:** Walk 516C sections with domain SMEs; select applicable criteria; record methods of compliance and evidence owners; baseline the document.
- **Trade-offs:** Facilitation time vs later fights over unstated expectations.

## 2. Criteria-to-Evidence Matrix
- **When:** Building airworthiness certification packages.
- **How:** One row per tailored criterion; columns for analysis/test/inspection artifacts and CM status.
- **Trade-offs:** Matrix maintenance vs audit scramble.

## 3. Installation-Inclusive Propulsion Closure
- **When:** Engine/propulsion supplier has its own credentials.
- **How:** Explicitly close air-vehicle installation criteria, not only unit-level evidence.
- **Trade-offs:** Integrator test cost vs in-service installation surprises.

## 4. Avionics + E3 Integrated Qual
- **When:** Mission systems or power/wiring changes.
- **How:** Plan functional, integration, and E3 evidence together; include UAS ground segment if applicable.
- **Trade-offs:** Broader test scope vs box-level false confidence.

## 5. Software Load Release Gate
- **When:** Flight software or propulsion/mission load updates.
- **How:** Airworthiness release checklist tied to Section 15 criteria and CM (loads, media, compatibility).
- **Trade-offs:** Release friction vs unapproved field software.

## 6. Crew Systems Early Geometry Freeze
- **When:** Cockpit/control-station layout still movable.
- **How:** Apply Section 9 accommodations/HMI/escape criteria before structures freeze bad envelopes.
- **Trade-offs:** Early human-systems engineering vs late waivers.

## 7. Tailoring Change Board
- **When:** Someone wants to drop or weaken a criterion.
- **How:** Require domain-qualified rationale and certification-basis revision under CM.
- **Trade-offs:** Governance overhead vs silent erosion of safety margin.
