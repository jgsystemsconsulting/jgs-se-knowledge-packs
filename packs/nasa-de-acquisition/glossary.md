# Glossary: nasa-de-acquisition (NASA-HDBK-1004A)

Terms synthesized from NASA-HDBK-1004A section 3 and related body use. Short definitions in pack words. Not a verbatim extract.

## Core terms

- **DE (Digital Engineering).** Integrated digital approach that uses authoritative sources of system data and models across disciplines for lifecycle work from concept through disposal.
- **DEE (Digital Engineering Ecosystem).** Connected set of data, models, tools, repositories, people, and processes that supports authoritative data and digital threads.
- **DE acquisition framework.** Set of approaches for acquiring data products and services that support DE processes; not an operational system product.
- **DRD (Data Requirements Description).** Data-item specification that states purpose, contents, format, timing, and control for a deliverable.
- **DPD (Data Procurement Document).** Collection of DRDs used with the SOW/PWS on a contract.
- **RCL (Recommended Contract Language).** Numbered handbook guidance statements selected and tailored before incorporation into a binding instrument.
- **PDI (Product Definition Information).** Information that defines the product.
- **PCI (Product Configuration Information).** Information that records configuration of the product.
- **CDM (Configuration and Data Management).** Discipline covering planning, identification, baselines, control, status accounting, and related audits for configuration and data.
- **CDMP.** Configuration and Data Management Plan.
- **CSA.** Configuration Status Accounting.
- **ASoT (Authoritative Source of Truth).** Named authoritative contractor or Agency source for a class of data.
- **MBSE.** Model-Based Systems Engineering.
- **MBD.** Model-Based Definition.
- **M&S.** Modeling and Simulation.
- **CAD.** Computer-Aided Design.
- **BOM.** Bill of Materials.
- **PLM / PDLM.** Product (Data and) Lifecycle Management families.
- **TDP.** Technical Data Package class of deliverable, often tailored with options that reference external TDP practice such as MIL-STD-31000C.
- **REF.** Requirements exchange style deliverable concept used with structured requirement objects.
- **MRI.** Master records index style deliverable for as-delivered build standard traceability.
- **Data Type (control scale).** Intensity of Government control over a data item, from strong approval patterns to inspection-only patterns.
- **FAIR.** Findable, Accessible, Interoperable, and Reusable attributes applied to data assets through metadata and shared access.
- **KDP.** Key Decision Point in the NASA program lifecycle.
- **SOW / PWS.** Statement of Work / Performance Work Statement.
- **FAR / DFARS.** Federal Acquisition Regulation and Defense FAR Supplement clause families named by the handbook; text not reproduced here.
- **CUI.** Controlled Unclassified Information.
- **COTS / GOTS.** Commercial / Government off-the-shelf.
- **CI.** Configuration Item.
- **CCB.** Configuration Control Board.
- **FCA / PCA.** Functional / Physical Configuration Audit concepts used with product baseline establishment.
- **SEMP.** Systems Engineering Management Plan.
- **Neutral format.** Non-proprietary or agreed exchange encoding that lets NASA systems load contractor data without a second reconstruction project.

## Notes

- Acronym expansions that appear only as list entries in section 3 and carry no extra pack meaning are omitted.
- When a term's binding definition lives in an external standard or NPR, this glossary records pack usage only and names the external source class without quoting it.
