# Cheatsheet: med-device-eu

Decision shortcuts. Each section names the chapter that carries the detail.

## Is this software a device? → ch02 (MDCG reading), ch03 (UK reading)

- EU: run the MDCG five-step decision; a medical purpose of its own qualifies the software as MDSW, then Rule 11 sets the class. (ch02)
- UK: read medical purpose from labelling, app-store text, and other claims; a calculation the intended user can easily verify stays unlikely to be a device. (ch03)
- Software that drives or influences a hardware device with no medical purpose of its own is a component or accessory, not stand-alone device software. (ch02, ch03)

## Which template does the question need? → ch05, ch06, ch07

- A notified body is assessing a manufacturer's clinical evaluation → the clinical evaluation assessment report, MDCG 2020-13. (ch05)
- The manufacturer is committing to post-market clinical activities → the PMCF plan, MDCG 2020-7. (ch06)
- The planned activities are done and the findings must be routed → the PMCF evaluation report, MDCG 2020-8. (ch07)

## Which regime does the question belong to? → ch01

- First sort EU from UK: MDCG guidance answers EU questions, MHRA guidance answers Great Britain questions; the question-to-document map is ch01. (ch01)
- A US FDA question belongs to the fda-med-device pack and gets no answer here. (ch01)
