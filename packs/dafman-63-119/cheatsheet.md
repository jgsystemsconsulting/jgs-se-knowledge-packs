# Cheatsheet — DAFMAN 63-119 (MOTRC)

## Decision rules
1. **Single OTRR briefing enough?** No — run continuous MOTRC with template reviews.
2. **Who certifies readiness?** Mission-Oriented Test Certification Official (TEMP-designated)—not the PM on MDAP/ACAT I–II/OSD oversight.
3. **When is the memo due?** ≥15 calendar days before OT start (or mutually agreed).
4. **Can OT start after memo alone?** No — OTO commander must acknowledge (concur/non-concur).
5. **Disagreement Official vs OTO?** Elevate to SAF/AQ and AF/TE.
6. **Increment or major software release?** Repeat final certification for that increment/release.
7. **Integrated data for OT credit?** Need characterization, traceability, relevance, scoring, config/data controls.
8. **Article not production-rep?** Argue operational-rep + fielding-intent; document OT limitations.
9. **Shortfall found?** Write testable exit criteria + get-well plan; do not hide in green status.
10. **Stop-test for poor performance?** Decertify → DT fix → recertify; do not infinite-pause.

## Tells & smells
| Smell | Likely gap |
|-------|------------|
| First MOTRC meeting is weeks before OT | Continuous process never started (ch01, ch03) |
| PM signed own MDAP certification | Independence violation (ch02) |
| TEMP Part III silent on certification | Strategy hook missing (ch07) |
| Templates answered yes/no only | No status narrative / risk (ch07) |
| Cyber first appears in OT plan | Missing continuous cyber thread (ch03, ch06) |
| No contractor data until final brief | Contract/CT oversight gap (ch05) |
| OTO non-concur ignored | Escalation path skipped (ch04) |
| Deferred requirements not in memo | Candor/traceability break (ch03, ch04) |
