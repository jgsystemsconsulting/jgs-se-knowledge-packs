# Cheatsheet — DOE O 413.3 Capital Asset PM

## Scope snap
- Covered capital asset projects above Order thresholds: full CD/PARS/EVMS regime as applicable.
- Lower TPC / minor construction: tailored principles still apply.
- Not for ordinary financial assistance/ESPCs (Order exclusions).

## CD memory aid
| CD | Intent |
|----|--------|
| CD-0 | Mission need |
| CD-1 | Alternative + cost range |
| CD-2 | Performance baseline |
| CD-3 | Start construction/execution |
| CD-4 | Operations start / completion |

## Control stack
1. Governance & applicability
2. CDs & authorities
3. Acquisition strategy + IPT + PEP
4. PB + cost/schedule + EVMS + PARS
5. Risk, safety/S&S interfaces, exemptions
6. Reviews, responsibilities, CRD, closeout

## Tells and smells
- **Smell**: CD labels without products or authority trail.
- **Smell**: Green EV with uncontrolled scope growth.
- **Smell**: Risk register disconnected from contingency.
- **Tell**: Change log distinguishes directed changes.
- **Tell**: CRD matches actual contractor scope.
