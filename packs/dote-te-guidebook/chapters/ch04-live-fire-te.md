# Chapter 4: Live Fire Test & Evaluation (LFT&E)

## Core Idea
LFT&E characterizes survivability (avoid/withstand/recover from combat threats) and lethality (defeat expected targets) against likely combat threats (10 U.S.C. 4172). It runs across the program from component through full-up system-level testing and is a DOT&E-centric enterprise responsibility for covered systems.

## Frameworks Introduced
- **Survivability + lethality mission**: Pair user platform protection with weapons effectiveness against expected threats.
- **Full-Up System-Level (FUSL)**: Combat-equipped, production-representative system testing early enough to fix design deficiencies before exceeding LRIP.
- **FUSL waiver is not an LFT&E waiver**: Statute/policy allow waiver only of FUSL/end-to-end form under a strict certification and alternative LFT&E plan path—not waiver of LFT&E itself.

## Key Concepts
- **Lifecycle LFT&E**: Component -> subsystem -> system building evidence; integrate early OT-relevant live-fire data where appropriate.
- **Oversight and certification**: DOT&E roles in LFT&E strategy/plan adequacy and waiver certification packages for covered programs.
- **Alternative plans**: When FUSL is waived, alternative LFT&E must still be grounded in actual testing sufficient for decision makers and congressional packages where required.
- **Integration with DT/OT**: Live-fire knowledge feeds survivability evaluation in OT and design fixes in DT; do not silo LFT&E as a late checkbox.

## Mental Models
- **You can waive a test configuration, not the need to understand combat damage and lethality.**
- **Early shots save redesign after LRIP lock-in.**

## Anti-patterns
- Treating LFT&E as optional because a FUSL waiver is pursued.
- Deferring all live-fire to after design freeze.
- Ignoring lethality when the program is a weapon, or survivability when it is a platform.

## Key Takeaways
1. LFT&E covers survivability and lethality under combat-threat realism.
2. FUSL is the end-to-end production-representative peak—not the only LFT&E activity.
3. Only FUSL/end-to-end may be waived, with certified alternatives.
4. DOT&E independence is central for covered programs.
