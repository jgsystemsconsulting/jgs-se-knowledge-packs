# Patterns — OMB Circular A-94 (2023)

## 1. OMB-Submission Grade BCA
- **When:** Analysis will support A-11/A-19 or legislative benefit-cost estimates to OMB.
- **How:** Follow A-94 end-to-end: baseline, alternatives, measurement, inflation match, prescribed rates, uncertainty, incidence, transparent report.
- **Trade-offs:** Higher documentation cost vs rejection or rework in clearance.

## 2. Real/Nominal Lockstep
- **When:** Building multi-year cash flows.
- **How:** Choose real or nominal units first; apply matching A-94 rate family; never mix in one NPV.
- **Trade-offs:** Slightly more setup vs invalid present values.

## 3. Opportunity-Cost First Costing
- **When:** Tempted to equate budget outlays with social cost.
- **How:** Map resource use to opportunity cost; separate transfers; include externalities.
- **Trade-offs:** Data difficulty vs biased program rankings.

## 4. Sensitivity Switch-Value Table
- **When:** Leadership asks 'how wrong can we be?'
- **How:** Vary top uncertain parameters; show values that flip the preferred alternative.
- **Trade-offs:** Analysis time vs false precision.

## 5. Dual Display — Efficiency + Incidence
- **When:** Programs with concentrated costs or benefits.
- **How:** Report unweighted NPV plus group incidence tables; disclose any weights.
- **Trade-offs:** Longer packages vs hidden equity fights later.

## 6. Appendix Rate Refresh
- **When:** Multi-year or recurring analyses.
- **How:** Track OMB discount appendix updates (e.g., Appendix C) and recompute before major submissions.
- **Trade-offs:** Maintenance vs using stale rates.

## 7. CEA When Monetization Fails
- **When:** Benefits cannot be credibly monetized.
- **How:** Hold effects constant or compare effect-per-cost; still discount costs correctly; state non-monetized limitations.
- **Trade-offs:** Less ranking power vs honest analysis.
