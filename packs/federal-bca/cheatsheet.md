# Cheatsheet — OMB Circular A-94 (2023)

## Decision rules
1. **Going to OMB (A-11/A-19/legislative estimates)?** Treat A-94 as mandatory.
2. **Internal planning only?** Still use A-94 as suggested good practice.
3. **Law/EO/other circular dictates method?** Those control over A-94 defaults.
4. **Real or nominal flows?** Match the discount-rate family—never mix.
5. **Public investment social BCA?** Use public-investment rate guidance + NPV.
6. **Benefits not monetizable?** Use CEA framing; still measure/discount costs rigorously.
7. **Only one NPV number?** Insufficient—add sensitivity and incidence.
8. **Army-specific CBA steps needed?** Not in this pack (A-94-only rescope); obtain ASAFM guide separately when available.

## Analysis spine
Baseline → Alternatives → Identify/measure benefits & costs → Inflation basis → Discount → Uncertainty → Incidence → Report

## Common rate mistakes
| Mistake | Fix |
|---------|-----|
| Nominal flows + real rate | Convert flows or switch rate family |
| Private WACC as default social rate | Use A-94 class-specific guidance |
| Stale appendix rates | Pull current OMB appendix |
| Risk buried only in higher rate | Separate time preference vs risk; show sensitivity |

## Tells & smells
| Smell | Likely gap |
|-------|------------|
| Budget outlays labeled 'social cost' | Opportunity cost missing (ch02) |
| No baseline narrative | Attribution failure (ch02) |
| Single-point NPV | Uncertainty skipped (ch04) |
| National total only for local project | Incidence missing (ch05) |
| Black-box spreadsheet | Reporting failure (ch06) |
