# Glossary — MIL-HDBK-338B

- **Availability** — Degree to which an item is operable when needed; forms vary (inherent vs operational). → ch01, ch09
- **BIT (Built-In Test)** — Onboard means to detect/isolate faults; central to testability claims. → ch07
- **Derating** — Using an item below rated stress levels to improve reliability. → ch03
- **Failure rate** — Instantaneous or average rate of failure used in many prediction models. → ch01, ch02
- **Fault tree analysis (FTA)** — Deductive logic model of causes of a defined top event. → ch06
- **FMEA / FMECA** — Inductive analysis of failure modes, effects, and (for FMECA) criticality. → ch06
- **FRACAS** — Failure Reporting, Analysis, and Corrective Action System. → ch08
- **Inherent reliability** — Reliability fixed by design/parts once the design is approved. → ch03
- **MTBF** — Mean Time Between Failures; meaningful only with stated conditions and model. → ch01, ch02
- **MTTR** — Mean Time To Repair; maintainability metric paired with reliability for availability. → ch01, ch09
- **Parts management** — Selecting, qualifying, and controlling parts used in the design. → ch03
- **Reliability allocation** — Assigning reliability budgets to lower-level elements. → ch02
- **Reliability demonstration** — Test program to show a requirement is met on a frozen design. → ch08
- **Reliability growth** — Planned improvement through test-analyze-fix cycles. → ch08
- **Reliability prediction** — Estimated reliability from models/parts data. → ch02
- **Sneak circuit** — Latent unintended path/condition not caused by component failure. → ch06
- **System effectiveness** — Broader mission success construct including R/M/A contributions. → ch09
- **Testability** — Design attribute enabling efficient detection and isolation of faults. → ch07
