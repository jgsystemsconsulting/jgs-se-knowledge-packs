# Glossary — MIL-STD-881F (WBS)

- **100% rule** — Child elements of a parent must represent 100% of the parent's work and resources. → ch01, ch03
- **Appendix K Common Elements** — Cross-commodity WBS elements (SE/PM, ST&E, training, data, support equipment, etc.) for A–J. → ch06
- **Appendix L Sustainment** — Sustainment cost reporting aligned to CAPE Sustainment CES (formal in 881F). → ch07
- **Appendix M Government ST&E** — Government system test and evaluation WBS definitions. → ch07
- **Contract WBS** — Contractor (or agreement performer) extension of the Program WBS for the contracted scope. → ch01, ch03
- **Commodity appendices A–J** — Standardized product structures for aircraft, electronics, missile/ordnance, strategic missile, sea, space, ground vehicle, unmanned maritime, launch vehicle, and IS/DBS. → ch04, ch05
- **Defense materiel item** — The PE-designated or otherwise designated item that owns the Program WBS. → ch01
- **IMP / IMS** — Integrated Master Plan / Schedule; must link to WBS products. → ch03
- **Level of identification** — Depth of WBS definition required for management (may exceed reporting level). → ch01, ch07
- **Program Element (PE)** — FYDP program element context for the defense materiel item. → ch01
- **Program WBS** — Government product-oriented structure for the entire program/materiel item. → ch01, ch02
- **SE/PM / SEIT/PM** — Systems engineering and program management (integration/test variants) common elements. → ch06
- **Subcontract WBS** — Lower-tier extension that still rolls to Contract/Program product parents. → ch03
- **WBS dictionary** — Authoritative definitions, inclusions, and exclusions for each element. → ch01, ch02
- **Work Breakdown Structure (WBS)** — Product-oriented family tree of hardware, software, services, data, and facilities. → ch01
