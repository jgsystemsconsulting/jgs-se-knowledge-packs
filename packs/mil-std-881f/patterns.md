# Patterns — MIL-STD-881F (WBS)

## 1. Commodity-First Skeleton
- **When:** Standing up a new Program WBS.
- **How:** Select the primary appendix (A–J), hang Appendix K commons at correct levels, write dictionary entries before RFP release.
- **Trade-offs:** Upfront taxonomy work vs months of irreconcilable contractor trees.

## 2. 100% Rule Guardrail Review
- **When:** Any proposed re-parenting or 'visibility' split.
- **How:** Check that children still sum to parent; reject orphaned former children promoted to siblings.
- **Trade-offs:** Less cosmetic visibility vs intact cost/technical rollups.

## 3. Dictionary as Interface Control
- **When:** Multiple IPTs share element boundaries (e.g., avionics vs airframe harnesses).
- **How:** Capture include/exclude lists and freeze via CM; update only with baseline changes.
- **Trade-offs:** Documentation overhead vs silent double-count/omit defects.

## 4. Software Placement Test
- **When:** Embedded software vs IS/DBS vs multi-function code.
- **How:** Prefer equipment parent; elevate only when effort cannot be partitioned; use Appendix J for DBS/IS.
- **Trade-offs:** Analytical effort vs meaningless Level-2 software buckets.

## 5. RFP Extension Clause
- **When:** Drafting solicitation WBS/CDRL language.
- **How:** Publish Program WBS + dictionary; require Contract WBS extension mapping; align CSDR/IMS identifiers.
- **Trade-offs:** Larger RFP package vs proposal chaos.

## 6. Reporting ≤ Definition
- **When:** Negotiating CSDR or management report levels.
- **How:** Define deep for risk items; report at negotiated levels without deleting lower definitions.
- **Trade-offs:** Heavier dictionary vs blind high-risk nodes.

## 7. Sustainment CES Crosswalk (Appendix L)
- **When:** O&S cost reporting / sustainment estimates on 881F programs.
- **How:** Use Appendix L CES alignment rather than overloading acquisition K logistics elements.
- **Trade-offs:** Dual-structure literacy vs wrong sustainment CERs.

## 8. Hybrid Commodity Justification
- **When:** Program truly spans two commodity spines (e.g., aircraft + major IS).
- **How:** Declare primary appendix, graft secondary with explicit parents and dictionary notes—never silent mashup.
- **Trade-offs:** Extra governance vs untraceable blended trees.
