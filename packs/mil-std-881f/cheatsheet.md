# Cheatsheet — MIL-STD-881F

## Quick facts
| Item | Value |
|------|-------|
| Designation | MIL-STD-881F |
| Date | 13 May 2022 |
| Supersedes | MIL-STD-881E (6 Oct 2020) |
| Role | DoD standard practice — WBS for defense materiel items |
| Spine | Program WBS → Contract WBS → Subcontract WBS |
| Commodity templates | Appendices A–J |
| Commons | Appendix K (for A–J) |
| Sustainment CES | Appendix L (formal in 881F) |
| Gov ST&E | Appendix M |

## 100% rule (one liner)
Children must represent **all** work of the parent—no orphaned promotions.

## Common elements to expect (K)
SE/PM (SEIT/PM), System T&E, Training, Data, Support equipment, Facilities/activation, Initial spares/repair parts, related logistics enablement — attached at the product level they serve.

## Pre-award checklist
1. Primary commodity appendix chosen  
2. K commons hung at correct levels  
3. Dictionary drafted  
4. High-risk nodes defined deeply  
5. RFP requires Contract WBS extension + ID alignment  
6. Government-performed slices included  

## Post-award checklist
1. Contract WBS under CM  
2. IMS/IMP tagged to WBS  
3. CSDR/report levels mapped  
4. Software/cyber placement reviewed at design freezes  
5. Appendix L sustainment path identified if O&S reporting applies  
6. Dictionary updated on splits/merges  

## Tells / smells
- Org-chart or cost-category WBS names  
- Single Level-2 'Software' or 'Cyber' for a whole weapon system  
- 'Other' elements with no specifications  
- Report IDs that do not match managed WBS IDs  
- Using only K logistics nodes to answer Appendix L sustainment questions
