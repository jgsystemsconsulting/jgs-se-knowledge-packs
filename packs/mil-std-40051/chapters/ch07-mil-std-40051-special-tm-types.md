# Chapter: Special technical manual types

## Core Idea

Appendices H through Q define special publication types beyond the core operator-maintenance-parts set. Each appendix states the technical content that type must carry. This pack names each type and its duty. It does not copy plates, forms images, or filled sample sheets.

## Frameworks Introduced

### Special-type map

| Appendix | Type |
| --- | --- |
| H | Destruction of equipment to prevent enemy use |
| I | Battle Damage Assessment and Repair (BDAR) |
| J | Preventive Maintenance Checklist (PMC) |
| K | Lubrication Orders (LOs) |
| L | Ammunition depot maintenance work requirements |
| M | Software users manuals and software administrator manuals |
| N | General maintenance manuals |
| O | Hand receipts (HRs) |
| P | Ammunition and munitions equipment data sheets |
| Q | Technical Bulletins (TBs) |

### How special types hang off the spine

Special types still obey section 4 structure and section 5 detailed controls unless the appendix states a type-specific override. Appendix A selection still decides whether the type is in the delivery set. Service prefixes may further limit a paragraph inside a special type.

### Representative duties (method only)

- **Destruction.** Content that tells maintainers how to deny equipment to an enemy when ordered.
- **BDAR.** Assessment and repair guidance usable under battle-damage conditions.
- **PMC and LO.** Checklist and lubrication products with their own content objects and update rhythm.
- **Ammunition DMWR and data sheets.** Depot-level ammunition maintenance requirements and data-sheet products.
- **Software manuals.** User and administrator software publications under the same standard practice.
- **General maintenance manuals.** Cross-cutting maintenance publications that are not a single end-item operator book.
- **Hand receipts.** Controlled inventory documentation tied to COEI/BII/AAL-style lists as the appendix requires.
- **Technical bulletins.** Supplementary technical publication content that is not a full TM rewrite.

## Key Concepts

- **Type is not a license to ignore the spine.** Special appendices add requirements; they rarely erase front-matter or WP discipline.
- **Forms-aware content.** Some types reference controlled forms (for example hand-receipt structures). The pack describes the duty; it does not reproduce form graphics.
- **Software is in the family.** Software user and administrator manuals are first-class types in this edition, not an afterthought.
- **TB as supplement.** Technical bulletins add or clarify; they do not silently replace the base TM without configuration control.

## Mental Models

- **Select the type, then load its appendix.** Do not mix destruction content into an operator book unless the matrix and configuration say so.
- **Battle and denial products are deliberate.** BDAR and destruction manuals exist because peacetime operator books are not enough.
- **Inventory products are publications too.** Hand receipts and data sheets follow publication discipline, not only property-book habit.

## Key Takeaways

- Appendices H-Q cover destruction, BDAR, PMC, LO, ammunition, software, general maintenance, hand receipts, data sheets, and TBs.
- Each type has its own content requirements on top of the shared spine.
- No plate, form image, or sample sheet is copied into this pack.
- Matrix selection still gates whether a type ships.
- ch08 covers how changes and notes apply across these types.
