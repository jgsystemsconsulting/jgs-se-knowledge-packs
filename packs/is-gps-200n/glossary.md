# Glossary — IS-GPS-200N ICD Exemplar

- **CCB** — Configuration Control Board; GPS Directorate authority that makes the IS effective. → ch01
- **CDMA** — Code-division multiple access; how SVs share L1/L2 frequencies. → ch02
- **CEI** — Clock, Ephemeris, Integrity data set; consume as one consistent bundle. → ch05
- **CNAV DC(t)** — Civil navigation payload (typed messages; App III). → ch04, ch06
- **DIST-A** — Distribution Statement A: approved for public release; distribution unlimited. → ch01
- **ICC** — Interface Control Contractor (cover names SAIC as watch-item only). → ch01
- **ICD / IS** — Interface Control Document / Interface Specification; this pack is a live IS exemplar. → ch01
- **ICWG** — Interface Control Working Group; 45-day PIRN review. → ch01
- **IRN / PIRN** — Interface Revision Notice / Proposed IRN; the change-paper path. → ch01
- **LNAV D(t)** — Legacy 50 bps navigation stream (App II for PRN 1–32, App IV for 33–63). → ch04, ch06
- **PRN** — Pseudo-random noise ranging-code identity assigned to an SV or other transmitter. → ch02
- **URA / UDRA** — User Range Accuracy / User Differential Range Accuracy indicators. → ch05
- **Z-count** — SV integer time count tying ranging epochs to NAV data. → ch05
