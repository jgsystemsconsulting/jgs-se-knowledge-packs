# Chapter: Users Guide for Performing MRL Assessments

## Core Idea

Appendix B describes the Excel-based MRL Users Guide that supplements the deskbook. The workbook is a separate artifact maintained by the MRL Working Group. This pack explains how to use that guide. It does not reproduce worksheet cells, pop-up text, or the printable matrix.

## Frameworks Introduced

### Why the workbook exists

The Users Guide gives assessors a single interactive place to navigate threads, levels, life-cycle context, definitions, and a question list derived from criteria. It supports assessments at any stage of acquisition or product development. The deskbook remains the narrative body of practice. The workbook is the operator console.

### Six named worksheets

1. **Introduction.** Instructions for operating the guide.
2. **Users Guide.** Main interactive sheet. Cells link to pop-up dialogs with detail on MRL topics, product life-cycle context, and thread information across the assessment view.
3. **Definitions.** Terms common in acquisition and MRL Assessment work.
4. **Acronyms.** Manufacturing, development, and acquisition acronyms.
5. **MRL Printable Matrix.** Whole-matrix view for on-screen review or print.
6. **Questionnaire.** Full question list derived from criteria, in table form, intended for tailoring.

### Pop-up behavior

Selecting a cell on the main Users Guide sheet opens a dialog that identifies sub-thread labels and maturity level context, among other detail. Assessors use pop-ups as navigation aids while scoring. Pop-up prose is not copied into this pack.

### Questionnaire practice

The questionnaire is meant to be copied, sorted, and trimmed. Limit questions to the target MRL and typically one level below. Focus on the system, subsystem, or component under review. A full untrimmed question dump for every level is rarely the right site-visit instrument.

## Key Concepts

- **External workbook.** Distribution and updates live with the Working Group materials, not inside this knowledge pack.
- **Tailoring is required.** Target level and item boundary drive which questions stay.
- **Matrix still authoritative in Appendix A.** The printable sheet aids reading. It is not a second criteria authority, and this pack still does not reproduce cells.
- **Definitions and acronyms.** Workbook lists support day-of assessment clarity; pack glossary absorbs deskbook Appendix E and key role terms.

## Mental Models

**Console, not contract.** The workbook helps teams apply criteria. It does not create FAR, DFARS, or SOW obligations by itself.

**Copy then cut.** Start from the questionnaire sheet, then delete questions outside the target band and item scope before the visit.

**Deskbook plus guide.** Narrative process lives in Chapters 4 and 5. Interactive scoring aids live in the workbook. Use both.

## Key Takeaways

- Appendix B is about an external Excel Users Guide with six worksheets.
- Main sheet pop-ups carry sub-thread and level detail without being reproduced here.
- Questionnaire tailoring to target level and item is expected practice.
- No worksheet cells appear in this pack.
- Pair the guide with the assessment process in Chapter 4 and MMP work in Chapter 5.
