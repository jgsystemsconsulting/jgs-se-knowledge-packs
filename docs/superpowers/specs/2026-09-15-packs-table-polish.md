# Spec: Packs table polish (P14)

- Date: 2026-09-15
- Package: P14, packs-table-polish
- Status: ready for implementation
- Owner: jgs-se-knowledge-packs maintainers

## Problem

`docs/packs.html` is a generated catalogue UI (filter tools, sticky table, mobile stacked
rows) driven by `tooling/gen_packs_page.py`. After P13 brand-token sync, the page inherits
the dark drafting tokens correctly, but table chrome, tools row, and sticky header still
read as first-pass layout: sticky header lacks stacking polish, tools sit bare against the
header copy, and spacing does not match the tightened drafting sheet on the landing page.
Hand-editing `docs/packs.html` would violate RR-B-00; polish must live in the generator
template and ship through regeneration.

## Evidence

- `docs/packs.html` header comment: GENERATED by tooling/gen_packs_page.py; do not hand-edit (RR-B-00).
- `tooling/gen_packs_page.py` template: `.tools`, `input#q`, `table`, `thead th` sticky, mobile
  stacked-row rules, separate from the BRAND-TOKENS placeholder.
- P13 owns shared `:root` and `@font-face` via BRAND-TOKENS markers in `docs/index.html`.
- P9-P11 own index hero/stills/OG; out of this package.
- Optional asset already on disk: `docs/assets/still-catalogue.png` (and `.svg`) from P11.

## Goal

Tighten packs catalogue table chrome, tools row, and sticky header readability inside the
generator CSS template only; regenerate `docs/packs.html`; optionally wire a small
self-hosted catalogue header still from `docs/assets/`. Keep BRAND-TOKENS extraction, do
not edit shared `:root`, do not change `docs/index.html` hero/stills/OG, do not hand-edit
the generated table body. Gates green.

## Research

research: skipped (in-repo generator CSS polish; no external API)

## Taste direction

Reading this as: catalogue reference page (filterable data table) for SE practitioners,
with the existing dark drafting document language, leaning toward restrained instrument
chrome on tools + sticky header, not a landing redesign.

Dials: VARIANCE 3, MOTION 1, DENSITY 6.

Rules:

1. Edit CSS (and optional still markup) only in `tooling/gen_packs_page.py` template.
2. Regenerate `docs/packs.html`; never hand-patch table rows.
3. Do not touch BRAND-TOKENS markers or `:root` values (P13).
4. Do not change `docs/index.html`.
5. Self-contained inline CSS; relative `assets/` only if still is wired; no CDN.
6. Em-dash-free durable prose (RR-B-28).

## Approach

Chosen: polish generator CSS for tools frame, sticky thead stacking/shadow, row hover and
spacing; optional small header figure reusing `docs/assets/still-catalogue.png`; regen
packs.html; mark P14 done.

Rejected:

- Hand-edit packs.html: violates RR-B-00 and freshness gate.
- Shared `:root` retune: P13 owns; would mix packages.
- New still generation: optional path already has catalogue still on disk.

## Acceptance criteria

1. Generator template CSS changes tools row, sticky thead, and table spacing/readability.
2. `python tooling/gen_packs_page.py` rewrites `docs/packs.html` and the committed page
   matches a fresh render (rr-b-30).
3. BRAND-TOKENS exclusive interior from index still appears verbatim in packs.html.
4. No edits to `docs/index.html` in this package.
5. No hand-edited table body rows (rows still come from SKILLS.md parse).
6. If a header still is wired, `img` src is relative under `assets/` and self-hosted.
7. Gates exit 0: `python tooling/test_html_assets.py`, `python tooling/test_ci_gate.py`,
   `python tooling/check_release.py`.
8. Packages doc marks P14 status `done`.
